## 任务
1. **指代消解**：如果当前问题中包含代词（"它"、"这个"、"那"）、省略或依赖历史对话的内容，请将其改写为完整、独立的自然语言问题。
2. **意图识别**：判断用户意图类型：制度查询 / 流程咨询 / 产品知识 / 故障排查 / 培训学习 / 其他。
3. **槽位抽取**：从问题中提取关键实体（如产品型号、故障代码、政策名称、时间、地点等）。
4. **标签预测**：从上述可用标签中，选择与问题最相关的 0-3 个标签。只选择明确相关的标签；不确定时返回空数组。不要猜测或编造标签。

## 输出格式
严格按以下 JSON 格式输出，不要输出其他任何内容：
```json
{
  "rewritten": "改写后的完整问题",
  "intent": "意图类型",
  "entities": ["实体1", "实体2"],
  "tags": ["标签1"]
}
```
